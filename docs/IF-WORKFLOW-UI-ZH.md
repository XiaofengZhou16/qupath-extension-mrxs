# IF 工作台与日常操作

在 `Extensions → MRXS → IF workflow / IF 工作台` 打开统一入口。

- **调色与发表图**：打开现有调色、预览及源像素导出窗口。
- **IF 分析与批处理**：打开分析窗口；配置可信模型后，可从固定底部操作栏进入项目批处理。
- **历史结果与报告**：浏览已有结果并选择报告。重复点击会回到已打开窗口，关闭后可以重开。

工作台显示当前切片及面积 ROI 的名称和外接框尺寸。无 MRXS 时禁用调色和分析入口，历史浏览仍可用。未选 ROI 时仍可打开分析设置，但运行单区域分析前必须选择面积标注。工作台本身不运行分析或更改参数。

分析窗口的“分析、取消、项目批处理”、进度和状态固定在底部，滚动设置和结果时不会消失。人工修正工具默认隐藏；需要时勾选“显示人工修正工具（可选）”，切换复核模式会自动显示。自动分析流程不要求人工修正。排除原因和结果轮廓查看仍直接可用。

这些修改不改变原始像素、阈值、分割算法或测量规则。JAR 哈希发生变化，因此恢复旧批次应使用原版本；新版本另建批次。不要修改保存的身份指纹绕过版本检查。

界面和工程回归测试不代表生物学准确率验证通过。正式研究使用前，应以独立参考与适当实验对照验证分割和表型判定；真实研究批次性能及报告分页也需按实际数据与运行环境检查。
