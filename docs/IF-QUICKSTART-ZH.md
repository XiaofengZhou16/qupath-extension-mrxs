# 多重免疫荧光工作流（开发版）

日常使用先打开 `Extensions → MRXS → IF workflow / IF 工作台`，按“调色与发表图 → IF 分析与批处理 → 历史结果与报告”进入相应窗口。简明入口说明见 [IF 工作台与日常操作](IF-WORKFLOW-UI-ZH.md)。下文保留详细参数、可选复核与结果格式说明；人工修正不是运行自动分析的必经步骤。

新增只读历史目录入口：`Extensions → MRXS → IF analysis → Browse saved analyses (read-only)`。
选择一次分析的目录或其直接父目录，后台读取完整记录并列出图像名、时间、ROI、分析层级、
标记及可测量候选数；取消、缺文件、损坏或不支持的记录会显示跳过原因。
不递归搜索整个磁盘，不修改历史输出。结构完整不等于数据内容已校验。
新记录保留几何坐标精度与多边形顶点顺序，用于插件内历史回放。旧版已舍入的轮廓
可能无法通过质心一致性校验；需要从原切片重新分析，不能靠旧文件恢复丢失的精度。
缺少来源信息的旧记录标为 `legacy_source_unknown`。当前新分析还会为本地源文件记录
大小、修改时间及头／中／尾抽样指纹，在分析前后与历史回放时比对。它不是完整文件
哈希；旧记录不会自动补上该保护，修改未抽样位置并保留时间戳仍可能不被发现。
记录表支持多选；下方显示所选记录的完整阈值配置。清空选择可查看全目录及跳过原因。
多选不会合并细胞或把多个 ROI 当作独立生物学重复。
现支持 Word/Excel 批量报告，以及来源匹配后的历史 ROI、可测量细胞和已导出 PA 掩膜恢复；操作与限制见文末。不会自动把记录套用到其他切片。

适用：QuPath 0.7.0、插件 `0.5.0-SNAPSHOT`。这些功能尚未自动安装到日常
QuPath；本地构建成功不等于已经发布。AI 与高清主视野仍需按自己的组织、
扫描批次和硬件验证，不能宣称与 SaiViewer 等效。

## 1. 先确认读到了原始通道

调色窗口点击 `Preview selected ROI / visible region` 后，会在后台显示每个已选通道
低于显示下限、超过显示上限的比例，以及恰好位于端点和非有限值的数量。修改显示范围
会使用已缓存的预览重新计算，不额外读取切片。计算期间会提示旧预览可能尚未更新。
这里统计的是预览包围框，包含 ROI 外部和孔洞；金字塔缩小也可能掩盖极值。
它不是染色阳性率或扫描过曝判定。最终仍需查看导出的 `display-qc.txt`，该文件按
所选导出层级和精确 ROI 掩膜重新统计。改变选区后须再次点击预览刷新。

AI 高级设置现可选择 `Padding`：16、32、48、64、80 或 96，默认仍为 32。
单位是模型输入像素，不是原始切片像素。增大重叠可能改变边界对象并增加计算量，
不保证准确率提高；请在固定 ROI、模型和通道下比较并人工复核。
实际值写入每次分析的 `segmentation.json` 和 manifest；“保存阈值配置”不会保存
AI 参数。当前可选值均满足最小 256 瓦片尺寸下 padding 小于半个瓦片的约束。

使用 AI 区域内独立的 `Save AI settings… / Load AI settings…` 保存、恢复设备、
工作线程数、瓦片尺寸、padding 和输入通道。加载时要求当前切片的完整通道名与顺序
一致；通道勾选按原始顺序送入模型，不接受自定义倒序配置，以免静默改变模型输入。
配置不包含模型路径、信任状态、荧光阈值或显示调色。加载不会运行模型，且会清除
模型信任勾选；请核对现有模型路径再确认信任。同一参数配置不代表使用了同一模型，
模型文件校验值仍应核对每次分析的来源记录。

开发版可编辑复核副本保持平铺轮廓。无轮廓批次容器的自动分组已撤回：在 QuPath
0.7 中，折叠含已选中细胞的批次会触发内部选择异常。请勿使用测试目录中的实验分组
项目作为日常分析项目。大量轮廓仍可能卡顿，不能宣称已解决大批量交互性能问题。
如果当前选中了细胞或细胞核，可点击 `Select owning review group / 返回复核组`，
显式选中所属复核组并切换到复核分析模式。此操作本身不启动分析；状态栏会提醒下一次
分析针对整组 ROI 和所有配对候选，而不是刚才选中的单个细胞。当前修复版允许 QuPath
在原生编辑后将轮廓移到图像根节点：只要所属组信息仍唯一且有效，就能找回原复核组。
若轮廓被放入另一个复核组、所属组缺失或组标识重复，则拒绝处理，避免混用复核组。
删除的轮廓不会重新出现；移动后不再包含配对核的细胞会列入排除原因。

人工修改后请显式使用 `File > Save`。移动整个矩形时面积可以不变，应同时核对质心；
改变边缘才会改变矩形尺寸。重开项目后核对位置，再返回复核组重新分析，另存新的结果。
已有导出表不会随项目编辑自动更新。当前真实指针验收覆盖了平移、保存、重开和重测，
不代表任意轮廓编辑或生物学分割准确率已通过验证。

打开 MRXS，保留同名数据目录。确认图像为独立荧光通道，而非只有 RGB 合成图。
核对扫描通道与抗体的对应关系，不能只靠颜色或文件名推断靶标。
先选一个有代表性的小区域，另保留阴性／单染等适当对照。

以下三类设置彼此不同：

| 设置 | 影响什么 | 不代表什么 |
|---|---|---|
| 通道颜色、显示上下限、Gamma | 屏幕合成及出版图外观 | 原始强度、阳性阈值或 AI 准确率 |
| 分割参数／模型输入通道 | 细胞、细胞核候选轮廓 | 各标记是否阳性 |
| PA／核均值／胞质均值阈值 | 原始通道统计与组合判定 | 显示亮度或分割阈值 |

## 2. 高清查看与调色

打开 `Extensions → MRXS → Display → IF color and publication export`。
逐通道检查预览、颜色、显示范围和 Gamma；预览按钮为
`Preview selected ROI / visible region`。换 ROI 后刷新。预览是外接矩形；
最终导出才按 ROI 轮廓及孔洞遮罩。

同一比较组尽量使用一致且记录在案的显示参数。保存显示配置，别把
“拉亮后看得见”当作阳性判定。调色不会改变本插件的原始强度统计。

需要 Retina 主视野时，可在同一 Display 菜单切换
`Toggle native HiDPI view (experimental)`；再次点击关闭。
`Show native HiDPI status` 显示设备像素尺寸及读取层级。
遇到交互问题先关闭实验模式，不修改原始图像。

高清来自正确源层级与设备像素匹配，不是把 DPI 数字调大。
若扫描文件实际只保存 8 位数据，不能通过显示或导出恢复原始 16 位信息。

## 3. 运行 IF 分析

结果窗口现明确提示：NPN、CPN、PN 的总体比例分母是具备有效核与胞质的可测量细胞，
不是全部 DAPI 细胞核；即使计算 NPN，也沿用此完整细胞入选规则。排除细胞不是阴性细胞。
没有细胞时，细胞阳性比例不可计算，不应填成零。屏幕组合计数为 inclusive（AB 包括 ABC）；
exact 结果另见导出表。PA 是像素重叠，细胞多标记共表达与分子共定位、相互作用不是同一结论。

另有独立核统计 `NPN_NUCLEUS_ONLY`：有效核不再依赖胞浆或细胞轮廓是否可测。
每次分析额外保存 `nuclei.csv`、`excluded-nuclei.csv`、`nuclear-combinations.csv`
和 `nuclei.geojson`。分母为有效且有采样像素的核，不是全部 DAPI 候选；缺核、
越界或无效轮廓仍被排除。旧的 NPN/CPN/PN 表不变，不应把两种 NPN 人群混合。
当前 Word/Excel 报告会分别标注这些结果，旧记录没有核补充表时显示不可用。

选中一个面积标注，打开
`Extensions → MRXS → IF analysis → Multiplex IF analysis`。

1. 选择待分析靶标，通常不要把 DAPI 当表型标记。阈值默认值仅为起点，
   必须结合对照校准。当前支持 1–8 个分析标记。
2. 选择统计金字塔层级并记录它。不同层级像素经过不同程度下采样，
   不应默认阈值与结果可以互换。放大屏幕不会改变统计层级。
3. 选择细胞来源：已有 QuPath 细胞、经典分水岭、可选 InstanSeg AI，
   或指定人工复核组。没有细胞时仍可做 PA，但不能报告细胞阳性比例。
4. 用 `Check selected ROI workload / 查看工作量` 查看工作量。大区域启动前
   会要求确认。它是外接矩形的像素估计，不是耗时／内存预测，也不是组织面积。
5. 保存到新目录并运行。取消后等待后台工作退出再重试；长时间底层读取或
   推理需安全返回，不保证即时停止。带 `INCOMPLETE` 的目录不可用于结果汇报。

经典分水岭不是 AI，其细胞扩张只是细胞边界近似。
InstanSeg 需另装官方 InstanSeg／DJL 扩展及可信
`fluorescence_nuclei_and_cells` 模型，选择模型目录并确认来源。
不要打开不可信模型。CPU／MPS 可选；分块尺寸、线程数和输入通道均会记录。
首次运行可能初始化或下载运行依赖，应先检查环境条件。
降低**统计**层级不会自动降低 AI 推理工作量；线程数也不等于底层 PyTorch
的全部线程数。优先用小 ROI 验证后再扩大。

## 4. 正确解读“共定位／共阳性”

新导出的 PA 掩膜采用 v2 存储：内容、尺寸完全相同的恒定瓦片共用 PNG，
每块的位置仍记录在 `area-masks/tiles.jsonl`。请保留完整目录，不按 PNG 文件数
推算覆盖面积。新插件兼容读取旧 v1；旧插件不能读取新 v2 掩膜。

- PA：达到原始像素阈值的像素面积。
- NPN／CPN：核／胞质原始均值达到阈值的细胞数。
- PN：每个标记按核或胞质任一阳性判定，每个细胞只计一次。
- inclusive AB 包括 ABC；exact AB 排除其他**已选**标记的阳性。
  改变分析标记集合会改变 exact 的含义。

查看 `combinations.csv` 的分母列：它可能是全部合格细胞、某单标记阳性细胞
或 ROI 采样像素。空分母不是零。ROI 不自动等于组织，空白区域也会进入
像素分母。细胞必须完整位于 ROI，且核／胞质都有采样像素才进入细胞统计。

像素重叠、同细胞共阳性和分子互作是不同问题；这里不自动给出
Pearson／Manders 指标，也不能据此证明分子互作。

## 5. 人工复核，不重复计数

分析后点 `Create editable review copy…`，确认创建独立复核组。
用 QuPath 标注工具编辑其中配对的 Cell／Nucleus 副本，保留配对元数据。
原始 detections 不被替换。之后选中**父复核组**，选择
`Selected editable IF review group`，重新运行，最后保存项目／图像数据。

漏检细胞：画外层细胞和内层核两个面积标注，多选它们及父复核组，点
`Add hand-drawn cell/nucleus pair…`。缺核细胞：多选父组、已有 Cell 及新核，
点 `Add missing nucleus to review cell…`。补核保留配对 ID，不新增一个重复细胞。
已有核不能通过补核覆盖，应编辑现有核。

`excluded-cells.csv` 列出排除原因；被排除不是阴性。
`invalid_cell_geometry` / `invalid_nucleus_geometry` 表示轮廓边界无效（例如自交），
不会自动修整后纳入统计。原始问题轮廓保留在排除记录中供复核；修复后再重新分析。
分析区域本身无效时会拒绝启动，请先修正该区域的边界。
完成分析后，“有效测量覆盖”显示可测量细胞 / 输入候选细胞及其比例；
没有候选时显示 N/A，不把未定义分母当成 0%。该比例不是 AI 准确率。
存在排除时，先检查被排除轮廓和首个失败原因，再解释阳性比例：
缺核、无可测胞质等选择性排除可能改变分母并造成偏倚。
`manifest.json` 的 `measurementCoverage` 保存同样的计数、比例、状态和复核提示。
开始下一次分析或取消、失败后，面板不会继续把旧覆盖率当作当前结果。
`excluded-cells.geojson` 是复核用标注，不是可直接重复导入计数的 detections。
勾选“Review excluded cells only”后，下方下拉框可按首个失败原因筛选橙色虚线轮廓：
例如 `missing_nucleus_roi`（缺少核）或 `no_valid_cytoplasm_pixels`（无有效胞质像素）。
选择“全部排除原因”恢复显示全部可绘制的排除对象；关闭复核模式后此筛选禁用。
它只改变显示，不修改数据或阳性分母。没有可绘制细胞轮廓的对象仍需查看 CSV。
“Previous / 上一个”和“Next / 下一个”可在当前原因内循环定位到细胞轮廓中心，
显示序号、原因及原细胞 ID；不改变缩放倍率或选中对象。切换原因会重置导航游标。
分析过程中禁止导航，重新分析会清空旧目标；需要保持原分析图像为当前活动视图。
复核模式 `segmentation.json` 保存本次配对及来源快照；它不是完整编辑历史，
也不代表已由专家验证。正式准确率评估仍需独立参考标注。

分析和出版导出的 `manifest.json` 现包含 `software`：插件版本、MRXS 读取器
修订号及实际插件 JAR 的 SHA-256。比较不同运行结果时应核对这些字段；
同为 `0.5.0-SNAPSHOT` 不表示二进制相同。哈希不可取得时会记录明确状态，
不会伪造。该信息识别的是导出插件，不证明输入切片或生物学结果已验证。
旧结果缺少这些字段时，不应自动推断为当前修复版。

## 6. 导出用于排版的通道组合图

在调色／导出工作台选择区域与通道，检查源层级及
`Check selected ROI dimensions`。开启 `Export every nonempty combination`：
选 A/B/C 会输出 A、B、C、AB、AC、BC、ABC，每组各有干净图和带标签图。
若同时选择 DAPI，它也参与组合数计算；N 个通道有 2^N−1 组，先确认范围。

可选 300／600 DPI、字体和带微米校准的比例尺，然后点
`Export publication panels…`。这是源像素渲染导出，不是屏幕截图。
DPI 控制排版物理尺寸，不通过插值增加源像素细节。干净 PNG 仍是显示合成图，
不能当多通道原始定量数据。

导出后查看 `display-qc.txt` 的显示范围截断情况；这不是扫描器饱和检测。
保留整个导出目录：`roi.json` 保存高精度选区，`display-profile.json` 保存显示参数，
`manifest.json` 记录这些文件与图片的校验值，以及可用的源文件抽样指纹。
若存在 `INCOMPLETE`，这次导出尚未成功，不应使用其中的部分图片。
源文件指纹不是全文件哈希，也不能证明染色特异性；重新排版时保留原始导出副本。
核对标记命名、比例尺、像素尺寸、背景截断和图中文字，再按目标期刊排版。
原始分析应使用原始通道及分析结果表，不能用调色后的 PNG 重新定量。

## 当前边界

已验证的是特定真实 MRXS 和自动化流程，包括并发结果一致性、取消重试、
部分源像素／金字塔及导出检查。尚不能据此承诺任意扫描仪兼容、全分辨率
整片 AI 性能、人工编辑的全部交互体验或特定组织上的生物学准确率。
保存原始数据、项目和参数；不要把开发版结果未经复核直接作为论文结论。
# 新增：历史记录批量报告（开发版）

本节的“批量”指历史窗口中多选已完成记录并导出报告。当前开发版另有
`Project AI batch… / 项目 AI 批处理…` 自动分析队列，操作见 [项目批处理简明说明](IF-BATCH-QUICKSTART-ZH.md)。
逐 ROI 分析的既有流程仍可使用：把输出保存在同一个父目录，再在历史窗口多选。
每个 ROI 保留自己的运行编号、阈值、分母和排除记录；重复分析同一 ROI 时，只选择
需要的版本，避免把旧结果与修正后结果重复汇总。队列的“导出批次结果”会按任务
选择最新且校验通过的完成尝试，并保留其余任务状态。

历史细胞：勾选 `Load saved measured cells / 载入历史可测量细胞` 后定位历史区域，可恢复已测量细胞的轮廓并按 PN 组合筛选；`Exact combination` 排除其他所选标记同时阳性的细胞。载入前核对 CSV/GeoJSON 的 ID、数量、NPN/CPN/PN、核中心及 ROI/平面。读取和空间索引构建在后台，不运行 AI、不添加项目对象。可测量细胞与排除记录分开显示，不能把排除细胞当成阴性。

历史独立核：选择 `Nucleus-only NPN / 独立核统计（替代 PN 轮廓）` 后点击定位。
该选项与完整细胞 PN 轮廓互斥，按核阳性组合显示，支持 inclusive/exact 筛选；
不会把核轮廓作为新的细胞对象添加进项目。缺少独立核结果的旧记录不会自动推断。
更改加载选项后需再次点击定位；切换图像或关闭历史窗口会清除临时轮廓。

### 历史结果的独立编辑与重新测量

对当前分析结果点击 `Create editable review copy…` 时，轮廓复制现于后台进行并显示进度，可用 `Cancel` 取消。任务真正退出前不能启动下一次分析；取消不添加半成品标注组。复制期间切换图像或关闭窗口，完成的副本不会添加到其他图像。最终加入项目标注树仍由界面线程执行，大型标注组可能需要等待。

目前的大规模限制：单次模拟测试中，10 万候选转为 20 万个可编辑轮廓时，标注树更新后的界面队列延迟峰值约 1 秒。后台复制不等于整个操作完全无卡顿。仅查看结果时可继续使用临时结果图层；需要人工修正时再创建副本。此数据来自简单矩形模拟，不是复杂真实组织的性能保证。

打开原切片，在历史窗口选中一条记录，点击 `Create editable copy… / 创建可编辑副本`。后台检查通过后，确认对话框会说明可编辑数量及完全没有轮廓的记录数；取消不会添加项目对象。确认后新增一个独立的复核标注组，不覆盖原历史文件，也不重新组织已有标注。

分析窗口会恢复历史通道、阈值、统计层级，并选择 `Selected editable IF review group`。修改组内成对的 Cell/Nucleus 标注后，选中整个复核组重新分析；结果写入新的目录，不重跑 AI。仍需检查阈值和轮廓，旧排除原因不代表修正后的资格或阴阳性。保存 QuPath 项目才能保留这些编辑。

有轮廓的排除对象也会复制，以便补核或修改边界；完全没有轮廓的记录仅保留在来源记录中，不虚构几何对象或算作阴性。新结果保存原结果目录、原参数、文件 SHA256、原候选/可测量数量及逐轮廓来源。文件一致性与路径/元数据匹配不等于原始切片像素认证，也不代表人工金标准。

历史排除记录：勾选 `Review exclusions / 复核历史排除细胞` 后定位，橙色虚线显示保存的细胞／核轮廓。可按排除原因筛选并点击前后按钮逐个定位，保留缩放倍率。界面区分只有细胞轮廓、只有核轮廓和无轮廓记录；没有可定位轮廓或中心在图像范围外的记录不会被伪造定位点，仍保留在总排除数中。此处是只读复核，不改变原分类、统计分母或历史结果，也尚不能直接编辑历史轮廓后重测。

历史 PA：勾选 `Load saved PA masks / 载入历史 PA 掩膜` 后定位。仅支持分析时已导出的掩膜；缺失、校验失败或参数不一致会拒绝加载，不会显示为全阴性。掩膜与细胞共享标记组合筛选，但 PA 表示像素阳性，PN 表示细胞表型，不能混用。PNG 按当前视野后台读取；视野超过缓存预算时提示放大。切换图像、清除历史显示或关闭窗口会关闭掩膜读取器。不会重新计算 PA，也不会重跑 AI。

历史定位：先打开原切片，在历史窗口选中一条记录，点击 `Locate ROI on current slide / 定位历史区域`。插件核对完整源 URI、读取器、图像尺寸、通道顺序、层级与像素标定后，定位到原 ROI 中心并用青色临时边界显示。不会修改项目对象或缩放倍率；切换图像或关闭窗口自动清除，也可手动清除。旧记录无来源信息、文件搬迁或元数据不匹配时拒绝定位，不按文件名猜测。元数据匹配不证明原始像素未被改写。

新运行的 GUI 分析会额外保存 `report-figure`：按启动时的通道开关、颜色和显示范围生成同一 ROI 的源像素合成图，记录关联校验值。报告预览最多约 100 万源像素，自动选择合适的原生层级；不截屏、不锐化、不放大补像素。无法满足标签尺寸等约束时明确记录不可用。它不替代原始分辨率发表图。批量 Word 报告现会校验关联清单、ROI 和图片后嵌入该合成图，保留 PNG 原始字节，仅设置页面显示尺寸。旧记录无关联图时显示缺图说明，不凭文件名自动配图；早期开发预览若声明有图但缺少 ROI 校验值，需重新生成，不能绕过校验使用。

在 `Extensions > MRXS > IF analysis > Browse saved analyses (read-only)` 中选择分析结果的父目录，多选需要的记录，勾选 Excel、Word 或两者，点击 `Export selected reports / 导出所选记录`，再选择保存位置。两者均不勾选时禁止导出。插件会自动创建独立的 `if-report-UUID` 子目录，不修改原分析结果。导出在后台执行，可取消；关闭窗口也会请求取消。

结果按勾选项包含 `results.xlsx`（逐运行组合明细、参数与来源）、`summary.docx`（运行摘要、关联图片、完整组合定量表），另有校验清单。仅导出 Excel 时不读取或验证 Word 配图，清单标记图片为 `not_requested`，不代表配图已验证。大量区域可优先只导出 Excel，避免不需要的 Word 排版与图片内存开销；表格数据校验仍完整执行。目录仍存在 `INCOMPLETE` 时不要作为完成报告使用。历史窗口“只读”是指不改写源分析，报告会另存新目录。

Excel 的计数、比例、密度和面积列现为数值，未定义比例仍为空。超出保守精度/范围限制的数值保留为文本以防失真；汇总计算前需检查文本例外（Excel 求和可能忽略文本）。图像名、运行编号及日期仍为文本，组合明细具有冻结表头和筛选。Word 现同时包含完整定量结果，按运行、包含/精确组合、指标及分母类型分组；跨页重复上下文和列标题。表中 Ratio 为 0–1 比例而非百分数；计数精确保留，Word 的比例、密度和面积按四位有效数字显示，完整精度请查原始 CSV。空值不是零。通道较多时 Word 报告可能很长，可缩小所选运行范围。尚未完成原生 Office 排版验收。重复 ROI/运行不会自动合并，也不能当成独立生物学重复。当前开发 JAR 尚未安装至日常 QuPath。


### 分类轮廓图（新增开发功能）

有可测量细胞几何的分析会额外输出 `classification-pn.svg`。它是可编辑的
矢量结果示意图，显示完整细胞测量人群的 PN 精确组合及对应核轮廓，
不是原始荧光图，也不显示被排除候选。请结合 `excluded-cells.csv` 审查
覆盖范围，不要把未显示对象算作阴性。Mask 0 表示未达到本次配置的标记
阈值，不等于生物学阴性。图例按分析标记命名，水平比例尺位于组织外。
缺乏物理标定时只显示源像素单位。完整几何和测量数据仍保存在 GeoJSON
及 CSV 中。保存整次分析目录以保留 ROI、参数和来源，不能只保留 SVG。

Word 报告的比率、密度和面积现按 4 位有效数字显示，小数极小时使用科学
计数法。计数和分母保持原值；精确数值应读取 CSV。此显示格式不改变
统计结果。新增分类图和报告格式的原生视觉验收仍按版本记录，不代表
本开发版已完成全部科研准确率验证。

### 鼠标编辑后对象位置变化（2026-11-11 修复版）

QuPath 可能在拖动轮廓后把 Cell 或 Nucleus 标注移到图像根层级。修复版按保留的复核归属标识识别这些对象，仍可使用“返回复核组”并重新测量；不必手动把它拖回。层级树中的组内对象数不等于重测候选数。要删除某个复核对象，应实际删除该标注，不能仅靠把它移出组来排除。若标注被放入另一个复核组，或复制导致组标识重复，程序会拒绝重测并要求纠正归属。

本修复已通过保存后真实像素重测；独立修复版应用的界面复验尚待完成。
